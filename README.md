# PizzaHub — Artisanal Pizza Ordering & Delivery Platform

![PizzaHub Banner](/pizza-logo.png)

> **PizzaHub** is a modern, full-stack artisanal pizza ordering and restaurant management platform. It connects food lovers with independent pizzerias, featuring wood-fired oven tracking, customizable delivery schedules, and role-based portals for customers, vendors, and administrators.

## 🍕 Project Overview

PizzaHub is built to provide an authentic culinary ordering platform:
- **Customer Portal:** Browse handcrafted pizzas, customize delivery dates, track orders in real time, and generate invoices.
- **Vendor Studio:** Manage pizzeria menu items, process kitchen orders, and upgrade listing capacity.
- **Admin Command Center:** Manage platform users, moderate menu submissions, and monitor activity.

---

## 🚀 Key Features

### 1. Customer Experience
- **Interactive Menu:** Browse authentic pizzas by category, search by pizza or pizzeria name, and sort by price.
- **Ordering System:** Select delivery date with validation and duplicate active order prevention.
- **Order Tracker:** Visual progress timeline tracking orders from review to baking and delivery.
- **Order Management:** View order history, cancel pending orders, and print official receipts.

### 2. Vendor Management
- **Menu Management:** Add, update, and manage pizza listings with high-resolution image uploads.
- **Kitchen Orders:** Real-time incoming orders list with one-click Accept and Reject controls.
- **Premium Subscription:** Stripe integration for tier upgrade to unlock unlimited listings.

### 3. Administrator Governance
- **User Management:** View registered users with one-click block/unblock capabilities.
- **Menu Moderation:** Review and approve or reject vendor pizza submissions.
- **Platform Analytics:** Overview of system activity, active orders, and transactions.
